# Las Vegas al volante

Un giro di notte sul circuito di Las Vegas con una Freccia d'argento: controller della Play, tastiera o tocco (iPad e telefono).
Si apre da https://niccolocarli22-lgtm.github.io/las-vegas-al-volante/ e si può installare come app.

Gioco non ufficiale, fatto per divertimento: nessun legame con la Formula 1, con la Mercedes o con altri marchi.
